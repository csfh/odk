# Icons

`remixicon/` holds the icons ODK draws (ADR 0080), unchanged from Remix Icon 4.8.0: the npm package `remixicon`, tarball `remixicon-4.8.0.tgz`, SHA-1 `52d16cc63f8557140ed39d5cb9c6403bccdddb68`, under the Apache License 2.0 in `remixicon/LICENSE`. Each file is the package's `icons/<category>/<name>.svg`.

Releases from 4.9.0 on carry the Remix Icon License v1.0 instead, so an icon is taken from 4.8.0. One from a later release is a licence decision first. To add an icon, copy its file here and give it a variant in `src/icon.rs`.
