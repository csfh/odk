# Plugins declare capabilities; the host app grants them, and the host's limits apply to them

Each Plugin carries its own small manifest listing which parts of the ODK Plugin API it needs, such as reading app state, adding UI, using the network or touching files. The host application decides which capabilities to grant. A Plugin is Luau running inside its host application's process (ADR 0003), so whatever applies to the host applies to the Plugin: the OS sandbox and the host's OMA permissions (ADR 0012) bound it exactly as they bound the host, and it can never exceed them. A Plugin granted network access by its host still fails to connect if the host's sandbox has no network. ODK does not read the Manifest to enforce this, which keeps the OMA and ODK sides separate (ADR 0013). Capability grants are a second, finer layer, enforced by the Luau sandbox, because the OS sandbox cannot tell a Plugin from its host.
