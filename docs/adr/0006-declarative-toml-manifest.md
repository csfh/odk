# The Bundle manifest is declarative TOML

Each Bundle carries a TOML manifest with a top-level `manifest_version = 1`. Required fields are `identifier`, `name`, `version` (semver), `executable` (a path inside the Bundle directory) and `permissions`; `icon` (PNG or SVG path), `categories` (freedesktop categories) and `description` are optional. Unknown fields are rejected so the format cannot drift silently. The identifier is a permanent reverse-DNS string such as `com.example.foo`; it names the application's data directory and `.desktop` entry, and two Bundles with the same identifier are the same application at different versions. The Manifest has no update fields because omalaunch does not update applications (ADR 0010). It contains no logic and no Lua, so omalaunch can read it, show the requested permissions and register the application without executing any code from the Bundle.
