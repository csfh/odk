# Target Omarchy on Wayland only

ODK and OMA target Omarchy (Arch Linux, Hyprland) and Wayland only. There is no X11 support and no support for other distributions or desktops. x86_64 comes first; aarch64 is added later. Narrowing the target lets omalaunch, the sandbox and the launcher integration rely on Omarchy's specifics instead of abstracting over every Linux desktop.
